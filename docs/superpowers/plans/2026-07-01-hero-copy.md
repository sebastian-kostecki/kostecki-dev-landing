# Hero Copy Refinement — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Update hero copy and aligned meta descriptions (PL/EN) so the first impression targets general backend recruiters — PHP/production-first value prop, Laravel in label/title only, niche mentioned lightly in subtitle.

**Architecture:** Content-only change. Hero text is read from `src/content/pl.json` and `src/content/en.json` via the existing `useContent` composable. `index.html` holds static Polish defaults for SEO crawlers and social previews before Vue hydrates locale state. No component or type changes required.

**Tech Stack:** Vue 3, JSON content files, Vite. No test framework in repo — verify with `pnpm build`, `pnpm lint`, and manual locale switch on `pnpm dev`.

**Spec:** `docs/superpowers/specs/2026-07-01-hero-copy-design.md`

---

## Verification model

This project has **no test framework**. Each task is verified with:

- `pnpm type-check` → expected: no TS errors.
- `pnpm lint` → expected: completes with no errors.
- `rg` spot-check → expected: old hero strings gone, new strings present.

Run `pnpm build` once after all tasks. Manual check on `pnpm dev`: hero shows new copy in PL; switch to EN confirms English variant; browser tab title/description update on locale switch (existing `App.vue` behaviour).

Commit after each task if the user requests commits; otherwise one commit at the end is acceptable.

---

## File Structure

**Modify only:**
- `src/content/pl.json` — `meta.description`, `hero.label`, `hero.valueProp`, `hero.subtitle`
- `src/content/en.json` — same fields
- `index.html` — `meta name="description"`, `og:description`, `twitter:description` (Polish defaults)

**Do not touch:** `HeroSection.vue`, About/Experience/Skills sections, `scripts/generate-og-image.mjs`, metrics bar values.
